# Bear Games — guía para el PIA

- Identidad: Bear Games; colores verde y blanco inspirados en FIME.
- Inicio: `home`; menú y búsqueda: `header`.
- Catálogo: `catalog`, `game-card`, `detail`, `games.ts`.
- Precios fijos: `prices` y el campo `price` en `games.ts`.
- Historia: `about`; chat automático: `chat`.
- Carrito: `cart` y `shop.service.ts`.
- CSS responsive: `src/styles.css`.

Para presentar el proyecto, ejecuta `npm start` y demuestra navegación, categorías, búsqueda, precios, carrito y chat. Incluye en el PDF requerido los datos del equipo, tecnologías, distribución de tareas, enlace del video y fuentes de las imágenes.
